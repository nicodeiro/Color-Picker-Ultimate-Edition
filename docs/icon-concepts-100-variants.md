# Color Picker Ultimate Edition - 100 variantes d'icone

Brief interprete: icone carree premium Apple-like pour l'extension Color Picker Ultimate Edition, inspiree des deux references fournies: UI blanche, grande pipette centrale, halo circulaire cyan/violet, ecran inspecteur avec pastille verte et historique de couleurs. Contraintes communes: icone uniquement, aucun texte, aucun logo Apple, aucune capture UI, fond clair satine/verre, pipette ou capture couleur lisible, couleur comme accent maitrise, pas de roue arc-en-ciel saturee, pas de fond sombre, pas de pipette medicale.
